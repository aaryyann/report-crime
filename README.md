# 🚨 Report Crime – Anonymous Crime Reporting Platform

Report Crime is a simple and effective web application that allows users to **anonymously report criminal activity**, **track the status of their reports**, and gives administrators the ability to **manage and update reports** via an admin dashboard.

---

## 🌟 Features

- 📝 **Anonymous Crime Reporting** – No login required
- 📊 **Track Report Status** – Users can check the status of their reports using a tracking ID
- 🛠️ **Admin Dashboard** – View and manage all submitted reports
- 🔄 **Status Update by Admin** – Admins can update the report status (Pending, In Progress, Resolved)

---

## 🛠️ Tech Stack

| Tech             | Description                          |
|------------------|--------------------------------------|
| **Next.js**      | React framework for SSR and routing  |
| **TypeScript**   | Strongly-typed JavaScript            |
| **Tailwind CSS** | Utility-first CSS for styling        |
| **PostgreSQL**   | Relational database for persistence  |

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/aaryyann/report-crime.git
cd report-crime
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Setup Environment Variables

Create a `.env` file in the root and configure your PostgreSQL connection:

```env
DATABASE_URL=your_postgresql_url
```

### 4. Run the Dev Server

```bash
npm run dev
```

### 5. Open in Browser

Visit [http://localhost:3000](http://localhost:3000)
